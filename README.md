# Swiggy Web Traffic & Conversion Analysis

## 📊 Project Overview

This project analyzes **Swiggy website traffic and conversion performance** using Tableau to understand how different traffic sources, user segments, devices, and engagement patterns influence website conversions.

The analysis focuses on identifying **high-performing traffic sources, conversion opportunities, and user engagement patterns** to support data-driven digital marketing and website optimization decisions.

---

## 🎯 Business Problem

The objective is to understand:

* Which **traffic sources** generate the highest number of conversions?
* Which sources have strong traffic but comparatively weak conversion performance?
* How does **conversion rate** vary across traffic channels?
* What is the relationship between **page views, bounce rate, and session duration**?
* How does website performance differ between **new and returning visitors**?
* How does **device type** affect traffic and conversion performance?
* Where are the major opportunities to improve website conversion?

---

## 📌 Key KPIs

| KPI                          | Purpose                                                    |
| ---------------------------- | ---------------------------------------------------------- |
| **Total Page Views**         | Measures overall website traffic                           |
| **Total Conversions**        | Measures completed conversion actions                      |
| **Conversion Rate**          | Measures the percentage of traffic resulting in conversion |
| **Bounce Rate**              | Measures visitors leaving without further interaction      |
| **Average Session Duration** | Measures user engagement                                   |
| **Traffic Source**           | Identifies the origin of website visitors                  |

### Conversion Rate

**Conversion Rate = (Total Conversions ÷ Total Visitors) × 100**

## 🔍 Analysis Performed

### 1. Traffic Source Analysis

Compared traffic sources to identify channels contributing the most traffic and conversions.

### 2. Conversion Performance

Analyzed conversion rates across traffic sources to identify efficient and inefficient acquisition channels.

### 3. Traffic Trend Analysis

Examined changes in website traffic and conversion performance over time.

### 4. User Behaviour Analysis

Analyzed:

* Page Views
* Bounce Rate
* Average Session Duration
* New vs Returning Visitors

to understand engagement behaviour.

### 5. Device Analysis

Compared website performance across different device categories to identify potential device-specific conversion opportunities.

## 💡 Key Business Insights

The analysis helps identify:

* Traffic sources that generate **high conversion efficiency**
* Traffic channels that generate **high volume but lower conversion**
* Differences in engagement based on **bounce rate and session duration**
* Conversion behaviour across **new and returning visitors**
* Device-level performance differences
* Potential areas for **traffic allocation and conversion optimization**

## 💼 Business Recommendations

Based on the analysis, businesses can:

1. Prioritize traffic sources with stronger **conversion efficiency**.
2. Investigate high-traffic channels with comparatively low conversion rates.
3. Improve landing-page and website experiences for high-bounce segments.
4. Optimize the experience for devices showing weaker conversion performance.
5. Develop different strategies for **new and returning visitors**.
6. Use conversion performance rather than traffic volume alone when evaluating acquisition channels.
